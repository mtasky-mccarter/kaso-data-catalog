# Purchasing publication fonts

Unmodified Liberation Sans Regular and Bold fonts, distributed with PDF.js,
are retained here so purchasing PDF generation has the same Slovak glyphs
and metrics on local machines and CI. The accompanying SIL Open Font License
and copyright notices apply to both font files.

Source: `pdfjs-dist/standard_fonts/` in the bundled artifact runtime.
Existing CP and VYD generators continue to use their existing fonts.
